# 첫 도서 대출 체크인

학교도서관 "미대출자 탈출" 행사용 웹앱입니다. 올해 아직 책을 빌리지 않은 학생이 이름을 검색하면 환영 화면이 나오고, 책을 빌리면 돌림판으로 간식을 뽑습니다.

- 이름 검색 → 첫 대출 학생은 "널 기다리고 있었어. 대환영!" 화면과 폭죽, 이미 빌린 학생은 "소중한 이용자" 화면
- 간식 돌림판: 직접 버튼을 눌러 돌리고, 여러 바퀴 돌다가 천천히 멈춤
- 친구 찬스: 아직 안 빌린 친구를 데려오면 데려온 학생도 간식 뽑기 (한 사람당 2번)
- 간식별 고정 확률 설정 (예: 인기 과자는 10명에 1번꼴)
- 관리자 모드: 엑셀 명단 붙여넣기, 간식 재고·확률 관리, CSV 내려받기

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 본체. 고칠 필요 없음 |
| `config.js` | 도서관 이름, 학교 이름, 교표, 관리자 비밀번호 |
| `data.js` | 처음 불러올 명단과 간식 (지금은 가짜 예시) |
| `assets/` | 교표 이미지를 넣는 폴더 |

## 써 보기

`index.html`을 더블클릭하면 브라우저에서 바로 열립니다. 서버나 설치가 필요 없어요.

- 관리자 모드 비밀번호는 `config.js`의 `pin` 값입니다.
- 기록은 그 컴퓨터의 브라우저에 저장됩니다. 관리자 모드의 "data.js로 처음부터"를 누르면 `data.js` 내용으로 다시 시작해요.

## 알아 둘 점

- 기록은 **열어 둔 브라우저 한 곳에만** 저장됩니다. 컴퓨터 두 대가 명단과 간식 재고를 실시간으로 함께 쓰려면 Firebase 같은 온라인 데이터베이스를 붙여야 해요.
- 실제 학생 명단은 이 저장소에 올리지 마세요. 공개 저장소는 누구나 볼 수 있습니다.
- 글꼴은 Google Fonts(Jua, IBM Plex Sans KR)를 불러옵니다.
